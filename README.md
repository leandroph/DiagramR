# 💧 Indicadores de Qualidade da Água

Este repositório contém um script em **R** desenvolvido para gerar um **fluxograma visual** dos principais **indicadores relacionados ao uso e à qualidade da água** em diferentes contextos, como consumo, armazenamento e reuso.

O fluxograma foi criado com o pacote `DiagrammeR`, e representa de forma clara e intuitiva o caminho da água desde o abastecimento até os critérios finais de qualidade.

---

## 📚 Contexto acadêmico

Este código foi elaborado como parte de um trabalho da disciplina **Sustentabilidade**, integrante do **Programa de Mestrado em Sustentabilidade dos Agroecossistemas**.

O objetivo é ilustrar os indicadores propostos para o **monitoramento do uso sustentável da água**, contribuindo com ferramentas visuais para análise e tomada de decisão.
